# 0.2.0 Access Profile Title Alignment

Date: 2026-06-17

## Objective

Keep the Access Profile workspace naming consistent across navigation, page title, and README. The page should not read like a separate "tenant permission console" when the operator is using it to inspect effective access.

## 中文说明

本次增量收束权限画像页命名：导航叫“权限画像”，页面标题也改为“权限画像”；内容区任务标题继续保留“租户访问画像”，用于说明该页是在租户范围内复核有效授权链和运行记录。

## Scope

- Frontend i18n copy.
- README product capability list.
- No route, API, or data model change.

## Changes

- Updated `page.access` from `Tenant Permission Console / 租户权限控制台` to `Access Profile / 权限画像`.
- Updated i18n regression coverage.
- Updated README capability wording.
