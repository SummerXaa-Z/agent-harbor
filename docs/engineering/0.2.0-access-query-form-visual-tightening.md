# 0.2.0 Access Query Form Visual Tightening

Date: 2026-06-17

## Objective

Keep Access Query as the answer-first entry point while making the query form feel like a standard B2B condition panel. The field groups should guide users without looking like multiple nested form cards.

## 中文说明

本次增量继续收束访问查询页：保留“先问清楚谁能访问什么”的产品路径，但把上下文和访问对象分组放进同一个浅色条件区。每个分组只保留标题和字段，不再各自绘制边框卡片，降低视觉噪音。

## Scope

- Frontend-only styling and regression tests.
- No backend API contract change.
- No access-query selection, handoff, live-data gating, or permission-change fix flow change.
- No copy or i18n key changes.

## Changes

- `ask-query-groups` now owns the single condition-panel background, border, and padding.
- Individual `ask-query-group` sections no longer render as nested cards.
- Added focused regression coverage to prevent the natural-language sentence layout or nested group cards from returning.

## Notes

- This is intentionally a visual tightening only. The Access Query interaction contract remains unchanged: prefill can come from resources/capabilities/access profile, and denied answers can start a permission change without auto-submitting it.
