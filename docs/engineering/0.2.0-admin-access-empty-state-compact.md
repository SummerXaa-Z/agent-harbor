# 0.2.0 Admin Access Empty State Compact

Date: 2026-06-17

## Objective

Keep Administrator Access Management consistent with the compact production empty states used by Resource Management, Route Policies, and Tool Capabilities. An empty administrator list should not render an eight-column table with no meaningful rows.

## 中文说明

本次增量处理“管理员与边界”页面的管理员列表空态：没有管理员记录或当前账号无权管理时，不再显示八列表头加空行，而是直接展示紧凑空态。有管理员记录时，原表格结构和行级操作保持不变。

## Scope

- Frontend-only change.
- No backend API contract change.
- No administrator identity model, creation, rotation, or disable behavior change.
- Existing non-empty administrator table layout is preserved.

## Changes

- Moved the empty administrator list out of the table body.
- Added `admin-access-empty-state` and reused the shared compact empty-state styling.
- Added regression coverage to prevent `td colSpan={8}` from returning to the empty path.
