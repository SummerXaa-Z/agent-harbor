# 0.2.0 Admin Identity Actor Format

Date: 2026-06-25
Branch: `codex/admin-identity-actor-format-preflight`

## Objective

Keep administrator actor names safe, stable, and readable across bootstrap config, managed administrator records, audit trails, approval routing, and operator sessions.

## 中文说明

管理员 actor 是生产系统里的审计主体和审批路由主体，不应该是自由文本。如果 actor 包含空格、斜杠、管道符、逗号、分号或控制字符，后续在环境变量解析、审批人匹配、审计检索和 UI 展示中都容易产生歧义。

本轮把 actor 收束为稳定机器标识：1-80 位字母、数字、点、下划线、连字符或 at 符号。这个规则同时用于 `AGENT_HARBOR_ADMIN_IDENTITIES` 引导身份和产品内创建的托管管理员身份。

## Scope

- Shared domain actor validation.
- Bootstrap admin identity parser.
- Managed administrator creation API.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering note.
- No frontend layout, storage schema, or dependency changes.

## Changes

- Added `domain.ValidAdminIdentityActor`, `domain.ReservedAdminIdentityActor`, and the shared syntax message.
- Updated `AGENT_HARBOR_ADMIN_IDENTITIES` parsing to reject invalid actor names after trimming and before duplicate checks.
- Updated managed administrator creation to reject invalid actor names and reserved built-in actor names.
- Extended `scenario-production-hardening.sh` to prove invalid actor format fails before PostgreSQL initialization and without credential leakage.
- Updated README, `.env.example`, release checklist, and changelog with the actor-format contract.
