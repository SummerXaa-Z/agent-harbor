# 0.2.0 Admin Identity Database Conflict Errors

Date: 2026-06-26
Branch: `codex/admin-identity-db-conflict-errors`

## Objective

Return stable client-facing errors when PostgreSQL rejects duplicate managed administrator identities.

## 中文说明

托管管理员 actor 已经在 API 层和数据库层保持唯一。API 层预检查可以处理正常请求，但并发创建时仍可能由 PostgreSQL 的唯一约束兜底。如果这个数据库错误直接冒泡，调用方会看到通用 `500 internal server error`，不利于管理员、Agent 或自动化调用方判断是输入冲突还是系统故障。

本轮把 `admin_identities` 插入时的已知唯一约束错误映射为稳定的 `409 Conflict`：重复 actor 返回 `ADMIN_IDENTITY_ACTOR_EXISTS`，极低概率的重复 id 返回 `ADMIN_IDENTITY_EXISTS`。其他数据库错误仍保持内部错误路径。

## Scope

- PostgreSQL store error mapping for managed administrator identity creation.
- Focused store unit tests.
- Changelog entry.
- No API route shape, storage schema, frontend layout, or dependency changes.

## Changes

- Added `adminIdentityInsertConflict` for known PostgreSQL unique constraints.
- Updated `createAdminIdentity` to return mapped conflict errors before wrapping unexpected database failures.
- Added internal store tests for known and unknown database errors.
