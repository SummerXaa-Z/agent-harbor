# 0.2.0 Admin Identity Scope Preflight

Date: 2026-06-25
Branch: `codex/admin-identity-scope-preflight`

## Objective

Reject misleading bootstrap administrator identity scope configuration before production startup.

## 中文说明

`platform_admin` 在运行时是平台级管理员，不会被租户或工作区字段限制。如果配置写成 `role=platform_admin|tenant=...|workspace=...`，操作者容易误以为这是一个限定范围的平台管理员，但实际权限仍然是平台级。

本轮把这种角色/范围不一致配置纳入 `AGENT_HARBOR_ADMIN_IDENTITIES` 解析和生产预检：`role=platform_admin` 不能包含 `tenant` 或 `workspace`；需要范围限制时应使用 `tenant_admin` 或 `security_reviewer` 并显式配置 `tenant`。

## Scope

- Bootstrap admin identity parser.
- Production deployment preflight.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering note.
- No API route, frontend, storage schema, or dependency changes.

## Changes

- Added role/scope consistency validation to `adminIdentitiesFromRaw`.

- Extended `scenario-production-hardening.sh` to prove scoped `platform_admin` identities fail before PostgreSQL initialization and without credential leakage.
- Updated README, `.env.example`, release checklist, and changelog with the stricter contract.
