# 0.2.0 Admin Identity Uniqueness

Date: 2026-06-17
Branch: `codex/admin-identity-uniqueness`

## Objective

Reject ambiguous bootstrap administrator identity configuration before AgentHarbor starts.

## 中文说明

`AGENT_HARBOR_ADMIN_IDENTITIES` 用于配置生产审批和范围化管理的引导管理员。如果同一个 actor 被配置多次，审计记录和会话恢复会无法明确指向唯一身份；如果同一个 key 绑定多个身份，登录后采用哪个租户/工作区边界也会变得不确定。本轮在启动配置解析期直接拒绝重复 actor 和重复 key，让部署问题 fail fast。

## Scope

- Backend-only startup configuration hardening.
- No API contract changes.
- No UI or i18n changes.
- No new dependencies.

## Changes

- Added duplicate actor detection while parsing `AGENT_HARBOR_ADMIN_IDENTITIES`.
- Added duplicate key detection while parsing `AGENT_HARBOR_ADMIN_IDENTITIES`.
- Documented the uniqueness requirement in README runtime configuration.
- Added regression tests for both duplicate actor and duplicate key cases.

## Notes

Managed administrator identities already enforce unique actors in the product. This closes the same ambiguity for deployment-time bootstrap identities.
