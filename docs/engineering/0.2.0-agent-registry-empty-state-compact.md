# 0.2.0 Agent Registry Empty State Compactness

Date: 2026-06-17

## Objective

Make the empty Agent Registry read like a production resource workspace instead of a large blank table. When no Agents are registered, the registry should explain the missing resource while keeping the actual creation action in the Resource Management command area.

## 中文说明

本次增量继续处理资源管理页的视觉密度：无 Agent 时，Agent 注册表不再展示居中大空态和“查看开始使用”跳转。用户已经在资源管理页，真正该做的动作是使用上方“创建 Agent”入口，因此空态改为左对齐紧凑说明，避免误导用户离开当前工作区。

## Scope

- Frontend-only change.
- No backend API contract change.
- No Agent filtering, status mutation, row selection, or details behavior change when Agents exist.
- Filtered-empty state remains in place for search/status filters.

## Changes

- Removed the no-Agent empty-state jump back to Getting Started.
- Updated the no-Agent empty-state copy to point to the in-page Create Agent action.
- Tightened the Agent Registry empty-state layout from a centered large placeholder to a left-aligned compact block.
- Added regression coverage for the no-Agent empty-state behavior and spacing.
