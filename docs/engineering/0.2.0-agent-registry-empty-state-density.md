# 0.2.0 Agent Registry Empty State Density

Date: 2026-06-17

## Objective

Make the Agent Registry empty state feel like a compact production-console hint instead of a large blank table placeholder.

## 中文说明

Agent 注册表在没有数据或过滤无结果时，本质上只是告诉管理员当前列表没有匹配项，不应该占据太大高度或使用过强的空态视觉。这个增量只收束 Agent 注册表自己的空态密度：降低高度、图标尺寸和文本规格，让页面更像标准 B 端管理系统的列表提示。

## Scope

- Frontend-only CSS and regression-test change.
- No backend API contract change.
- No Agent query, status filter, row action, details panel, or data rendering behavior change.
- Global `EmptyRow` styling is unchanged; only Agent Registry overrides are tightened.

## Changes

- Reduced `.registry-empty-state` minimum height from 96px to 72px.
- Reduced the Agent Registry empty-state icon from 36px to 28px.
- Reduced the Agent Registry empty-state copy to compact list-level text sizing.
- Added regression coverage for the compact Agent Registry empty-state density.
