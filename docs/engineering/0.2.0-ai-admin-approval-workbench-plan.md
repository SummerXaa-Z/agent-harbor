# 0.2.0 AI Admin Approval Workbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the approval-required permission package journey executable from the Web Console AI Admin workspace.

**Architecture:** Keep the existing REST API as the source of truth. Add a small frontend journey helper for deterministic demo identifiers and evidence evaluation, then wire the existing AI Admin workbench to create tenants, caller, MCP target, capabilities, approval request, approved apply, runtime MCP calls, access profile, application, and audit evidence through live APIs. Keep fallback data conservative: approval-required live runs require the API and mock MCP service.

**Tech Stack:** React, TypeScript, Vite, existing AgentHarbor REST API client, node:test frontend tests, in-app browser verification.
