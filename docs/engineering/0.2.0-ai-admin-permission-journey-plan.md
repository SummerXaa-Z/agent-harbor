# AI Admin Permission Journey Implementation Plan

> **For agentic workers:** implement this plan task-by-task and keep each step verified before moving on.

**Goal:** Add the first v0.2.0 product slice where a non-technical administrator can describe a permission need, select a permission package template, preview the resulting allow/deny plan, and apply the package through the existing tenant/workspace/caller grant APIs.

**Architecture:** Keep permission packages as deterministic frontend templates for this slice, then apply them through the existing live API objects: capability approval, tenant entitlement, workspace assignment, and caller instance assignment. This avoids a new persistence model while proving the journey with real control-plane writes and existing access-profile evidence.

**Tech Stack:** React 19, TypeScript, Node test runner, Go API, existing AgentHarbor management APIs.
