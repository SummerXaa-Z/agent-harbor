# 0.2.0 Approval Reviewer List Default

Date: 2026-06-25
Branch: `codex/approval-reviewer-list-default`

## Objective

Make approval request list reads default to the authenticated reviewer queue for non-platform administrators when approval reviewer routing is configured.

## 中文说明

上一轮已经把显式传入的 `reviewer` 绑定到认证管理员身份，避免调用方冒充其他审批人。但 REST 审批请求列表和管理 MCP 列表工具在省略 `reviewer` 时仍会退回普通管理范围列表。对安全审核员来说，这会绕过“只能看自己路由队列”的产品语义。

本轮修复后，只要配置了审批人路由，非平台管理员省略 `reviewer` 也会默认读取当前认证 actor 的审批队列。平台管理员仍可省略 `reviewer` 查看全局队列，用于运营总览和排障。

## Scope

- REST approval request list default reviewer resolution.
- Management MCP `list_permission_package_approval_requests` default reviewer resolution.
- Focused backend tests for omitted-reviewer list reads.
- README and changelog updates.
- No frontend, schema, storage, or dependency changes.

## Changes

- Added `listPermissionPackageApprovalRequestsForRequest` as the shared read path for REST and management MCP approval request lists.
- Added `permissionPackageApprovalListReviewer` to resolve list scope:
  - explicit `reviewer` still must match the authenticated admin actor;
  - no reviewer routing keeps the existing general list behavior;
  - platform administrators can still omit `reviewer` for all-queue visibility;
  - non-platform administrators with reviewer routing default to their authenticated actor queue.
- Kept development unauthenticated preview behavior compatible.
