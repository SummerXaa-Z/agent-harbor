# 0.2.0 Capability Empty Primary Action

Date: 2026-06-17

## Objective

Make Capability Governance guide operators to discover capabilities before creating a grant chain when the selected MCP target has no loaded tools.

## 中文说明

资源管理会把“缺工具能力”的下一步引导到工具能力页。到达工具能力页后，如果当前目标还没有能力，主按钮不应该继续展示“创建授权链”，因为这会打开一个无法完成的表单。本次增量把空能力状态下的主动作切换为“刷新能力”，让管理员先完成能力发现，再进入授权链创建。

## Scope

- Frontend-only Capability Governance behavior change.
- No backend API change.
- No new dependency.
- No permission write behavior change.
- No automatic refresh or automatic grant submission.
- Reuses existing bilingual copy for capability refresh.

## Changes

- Kept the catalog primary `创建授权链 / Create grant chain` action only when the selected target already has discovered capabilities.
- Added a catalog primary `刷新能力 / Refresh capabilities` action when the selected target has no capabilities.
- Reused the existing refresh loading state and disabled state so duplicate refresh clicks are blocked while the target refresh is running.
- Added structural tests to prevent the empty capability page from regressing to an unusable grant-chain entry.
