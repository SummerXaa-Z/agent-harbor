# 0.2.0 Capability Empty State Compact

Date: 2026-06-17

## Objective

Keep the Tool Capabilities workspace visually consistent with Resource Management and Access Policy empty states. When no capabilities have been discovered, operators should see a compact setup prompt instead of a table with no useful rows.

## 中文说明

本次增量处理工具能力目录的空态：没有发现任何工具能力时，不再显示搜索栏、表头和空行，而是展示紧凑配置引导。只有在已有能力但被搜索或状态筛选过滤为空时，才保留表格语境，帮助用户理解这是筛选结果为空。

## Scope

- Frontend-only change.
- No backend API contract change.
- No capability discovery or grant behavior change.
- Existing non-empty capability table layout is preserved.

## Changes

- Added an explicit `hasTargetCapabilities` branch in `CapabilityGovernanceView`.
- Rendered a standalone `capability-empty-state` when no target capabilities exist.
- Kept the filtered no-result state inside the table.
- Reused the compact empty-state styling shared with route policies.
- Added regression coverage to keep no-capability empty states out of table chrome.
