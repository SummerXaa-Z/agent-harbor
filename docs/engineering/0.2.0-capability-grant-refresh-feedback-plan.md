# AgentHarbor 0.2.0 Capability Grant Refresh Feedback Plan

## Goal

Make direct capability grant-chain creation remain visible and accurately reported when the follow-up console refresh fails.

## Design Consensus

- Keep existing grant-chain write APIs unchanged.
- Merge the returned tenant entitlement, workspace assignment, and instance assignment into `ConsoleData` before running the broader refresh.
- Treat follow-up refresh failure as stale list feedback, not as a failed grant-chain creation.
- Keep fallback-data behavior unchanged for local/demo capability fallback paths.
