# 0.2.0 Capability Grant Required Fields

Date: 2026-06-17

## Objective

Prevent Capability Governance from submitting a grant chain when required tenant, workspace, caller, capability, or access-object context is missing.

## 中文说明

能力审批完成后，管理员会进入创建授权链表单。如果调用方 Agent 还没有创建或没有被选中，之前表单仍允许点击“创建授权链”，然后才在页面顶部显示失败信息。这不符合生产系统的体验，也会打断主旅程。本次增量把校验前置到表单内：上下文不完整时禁用提交，并在缺调用方时直接引导回资源管理。

## Scope

- Frontend-only Capability Governance form validation and guidance.
- No backend API change.
- No new dependency.
- No automatic Agent creation.
- No permission grant behavior change once the form is complete.
- All new visible copy is bilingual.

## Changes

- Added `grantFormReady` derived state in the Capability Governance view.
- Disabled grant-chain form submission while required context is incomplete or the grant write is already running.
- Added an inline grant-form blocker for missing caller Agents.
- Linked the missing-caller blocker to Resource Management so administrators can create/select the caller before retrying the grant.
- Added structural tests, i18n coverage, and style coverage for the blocker.
