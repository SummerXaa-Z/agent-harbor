# 0.2.0 Capability Handoff Context

Date: 2026-06-17

## Objective

Keep operators oriented when Resource Management sends them to Capability Governance.

## 中文说明

资源管理已经成为 Agent 和 MCP 生命周期的统一入口。之前点击资源的“发现能力”后，工具能力页只会预选目标 Agent，但页面没有明确说明这是从哪条资源处理链路带入的，用户容易误以为自己跳到了另一个孤立页面。本次增量在工具能力页顶部加入可关闭的上下文提示，展示来源、目标 Agent、租户和工作区，让“资源管理 -> 发现能力 -> 创建授权链”保持同一条任务线。

## Scope

- Frontend-only handoff context change.
- No backend API contract change.
- No capability discovery, capability approval, grant-chain creation, permission change, or routing behavior change.
- Added bilingual copy for the new Capability Governance handoff notice.

## Changes

- Added a typed `CapabilityGovernanceHandoffContext`.
- Updated the Resource Lifecycle action planner so `review_capabilities` carries target, tenant, and workspace context.
- Stored the capability handoff context in the console controller when the operator starts from Resource Management.
- Cleared the handoff context when the operator dismisses it or manually switches the selected target.
- Rendered a compact Capability Governance notice with business-readable target, tenant, and workspace labels.
- Added regression guards for planner output, controller wiring, view rendering, styling, and Chinese copy.
