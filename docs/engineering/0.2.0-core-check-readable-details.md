# 0.2.0 Core Check Readable Details

Date: 2026-06-17

## Objective

Keep the System Self-Check useful for non-technical operators by removing generated tenant, workspace, endpoint, and run identifiers from the primary check rows. The raw details remain available for troubleshooting, but the visible row text should answer what state the check is in.

## 中文说明

本次增量处理系统自检页的检查项明细：此前主界面会直接显示 `tenant-root-...`、`workspace-sandbox`、`ui-core-...` 等技术字段，用户需要自行理解这些字段代表什么。现在主路径展示“等待创建三级租户范围”“授权链尚未完整串联”等状态说明，原始明细保留在悬停标题里，便于需要排障时查看。

## Scope

- Frontend-only change.
- No backend API contract change.
- No self-check evaluator behavior change.
- No change to generated run IDs, tenant IDs, workspace IDs, or audit data.
- Adds a pure presentation helper for translating self-check row states.

## Changes

- Added `coreJourneyStepDetailLabel` as a pure presenter for self-check step row copy.
- Updated `CoreJourneyWorkbench` to render the readable detail as primary text.
- Preserved raw step details in the row title for troubleshooting.
- Added bilingual copy for every self-check step and status combination.
- Added regression coverage for readable details and component wiring.
