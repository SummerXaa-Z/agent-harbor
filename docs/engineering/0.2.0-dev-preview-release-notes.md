# AgentHarbor v0.2.0 Developer Preview Release Notes

Status: draft notes for the `v0.2.0-dev-preview` tag.

This preview is intended for local evaluation, design feedback, and early contribution. It is not recommended for production traffic.

## Highlights

- Tenant-first permission operations across tenants, workspaces, caller instances, capabilities, and data scopes.
- Permission Changes journey for deterministic package drafting, simulation, approval-required apply, preflight, application health, impact review, go-live status, and acceptance-report export.
- Scoped and managed administrator identities with tenant/workspace boundaries, key rotation, disablement, and lifecycle audit records.
- Tenant Permission Center and Access Profile views for governance review.
- Management MCP tool metadata for safety, access, lifecycle, execution, and confirmation-aware write calls.
- Local evaluator pack via `make evaluation-readiness`, including environment snapshot, walkthrough, feedback log, and acceptance-report notes.

## Known Limits

- Developer preview only; no production-traffic recommendation.
- No customer-specific MCP endpoint validation is included in this tag.
- No IdP integration.
- No Access Handoff or My Access self-service yet.
- No first-class database, warehouse, model, or skill-bundle resource type yet.
- No automated rollback execution.
- No production multi-region deployment guarantee.
