# 0.2.0 Disabled Admin Disable Conflict

Date: 2026-06-26
Branch: `codex/disabled-admin-disable-conflict`

## Objective

Reject repeated managed administrator disablement after an identity is already disabled.

## 中文说明

托管管理员禁用是一个生命周期事件，不应该被重复记录成多次成功操作。此前对同一个 disabled 身份再次调用 disable 会返回 `200 OK`，刷新 `disabledAt`，并追加新的 `admin_identity.disabled` 审计事件。这样会让审计链看起来发生了多次独立止损动作，降低生产排障和合规复盘的可信度。

本轮把重复禁用收敛为稳定的 `409 ADMIN_IDENTITY_DISABLED`。第一次禁用仍然记录审计事件；后续重复禁用不会修改身份状态，也不会追加生命周期审计噪声。
