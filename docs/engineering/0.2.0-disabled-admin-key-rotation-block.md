# 0.2.0 Disabled Admin Key Rotation Block

Date: 2026-06-26
Branch: `codex/disabled-admin-rotation-block`

## Objective

Reject managed administrator key rotation after an identity has been disabled.

## 中文说明

托管管理员禁用是生产止损动作。禁用后，该身份的 key 和浏览器 session 都应该停止可用。此前服务端仍允许对 disabled 身份执行 key rotation，并返回新的明文一次性 key；但身份状态仍是 disabled，这个 key 实际无法登录。

这会给管理员制造错误信号：看起来已经拿到“新 key”，实际上无法恢复访问。为了避免无意义密钥材料和操作误导，本轮在 rotate 路径对 disabled 身份返回稳定的 `409 ADMIN_IDENTITY_DISABLED`。

## Changes

- Added an active-status guard before managed administrator key rotation.
- Returned `409 ADMIN_IDENTITY_DISABLED` for disabled identity rotation.
- Extended `TestManagedAdminIdentityLifecycleAndScopedLogin` to prove disabled identities cannot rotate keys and do not emit extra lifecycle audit actions.
- Extended `scenario-admin-access-management.sh` to enforce the same behavior in the release gate.
- Updated changelog and release checklist wording in English and Simplified Chinese.
