# Frontend Bundle Warning Cleanup

## Goal

Keep the production web console under Vite's default chunk-size warning budget without hiding the warning or raising `chunkSizeWarningLimit`.

## Problem

The console entry had become a single broad workspace bundle. The production build still succeeded, but Vite emitted the default warning because the main application chunk exceeded `500 kB` after minification. That warning is useful for public-readiness work, so the fix must split the bundle instead of disabling the signal.

## Changes

- `ConsoleController.tsx` now lazy-loads the heaviest workspace panels:
  - `AiAdminPermissionWorkbench`
  - `CapabilityGovernanceView`
  - `TenantOrganizationView`
- The main workspace content is wrapped in a React `Suspense` boundary that reuses the existing loading skeleton.
- `frontend/tests/viteConfig.test.mjs` now guards the lazy-load boundary so the heavy panels cannot silently move back into the initial entry chunk.
