# 0.2.0 Managed Admin Bootstrap Actor Uniqueness

Date: 2026-06-25
Branch: `codex/managed-admin-bootstrap-actor-uniqueness`

## Objective

Prevent managed administrator identities from reusing bootstrap administrator actors.

## 中文说明

管理员 actor 是控制台 session、管理审计、审批人路由和权限边界的共同主体标识。如果托管管理员允许复用引导管理员 actor，后续禁用、轮换、审计归因和审批路由都会变得含混。

服务端创建托管管理员时已经会检查 bootstrap actor 和已有 managed actor。本轮把这条生产边界补成明确测试和场景门禁：尝试创建 `actor=platform` 的托管管理员必须返回 `400`，并说明 `actor already exists`。
