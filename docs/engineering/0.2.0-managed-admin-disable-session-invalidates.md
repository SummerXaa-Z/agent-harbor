# 0.2.0 Managed Admin Disable Session Invalidation

Date: 2026-06-25
Branch: `codex/managed-admin-disable-session-invalidates`

## Objective

Make managed administrator disablement an explicit browser-session containment guarantee.

## 中文说明

托管管理员禁用通常发生在人员离岗、权限误配或密钥风险处置时。仅拒绝禁用后的新登录还不够；禁用前已经打开的控制台 session 也必须立即失效，否则管理员仍可能继续写管理 API。

服务端 session 校验已经会回查托管管理员状态。本轮把这个生产安全边界补成可验证契约：HTTP API 生命周期测试和生产场景脚本都会在禁用前保存浏览器 session cookie 与 CSRF token，并在禁用后复用它们执行管理写入，预期结果必须是 `401 Unauthorized`。

## Scope

- Managed administrator lifecycle HTTP API test coverage.
- Managed administrator lifecycle production scenario coverage.
- README, changelog, and release checklist wording.
- No runtime behavior, storage schema, frontend layout, or dependency changes.

## Changes

- Extended `TestManagedAdminIdentityLifecycleAndScopedLogin` to prove a pre-disable managed browser session cannot write after identity disablement.
- Updated `scenario-admin-access-management.sh` to capture the rotated-key browser session and verify it is rejected after administrator disablement.
- Updated README and release checklist to describe disablement as an immediate containment action for existing browser sessions.
- Added changelog entries in English and Simplified Chinese.
