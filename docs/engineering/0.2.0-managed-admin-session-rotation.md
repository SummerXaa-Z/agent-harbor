# 0.2.0 Managed Admin Session Rotation

Date: 2026-06-25
Branch: `codex/managed-admin-session-rotation`

## Objective

Invalidate managed administrator browser sessions issued before a managed administrator key rotation.

## 中文说明

托管管理员密钥轮换是生产止损动作。如果旧 key 已经失效，但轮换前签发的浏览器 session 仍可继续写管理 API，轮换就不能完整切断已泄露的管理入口。

本轮在控制台 session token 中写入签发时间，并在验证托管管理员 session 时比较该身份的 `RotatedAt`。如果 session 签发早于最近一次密钥轮换，服务端会把该 session 当作无效登录处理。共享 `AGENT_HARBOR_ADMIN_KEY` 和开发绕过主体不受托管管理员 `RotatedAt` 影响。

## Scope

- Console session payload and verification.

## Changes

- Added `issuedAt` to newly signed console session payloads.
- Updated console session verification to reject managed administrator sessions issued before `RotatedAt`.
- Kept legacy session token handling deterministic by deriving missing `issuedAt` from `expiresAt - defaultConsoleSessionTTL`.
- Extended managed administrator lifecycle test coverage to prove old browser sessions cannot write after key rotation.
- Extended `scenario-admin-access-management.sh` to capture managed login cookie/CSRF and verify pre-rotation sessions are rejected after key rotation.
- Updated README, changelog, and release checklist with the session invalidation behavior.
