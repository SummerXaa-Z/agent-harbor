# 0.2.0 Management Audit Empty State Compact

Date: 2026-06-17

## Objective

Keep Management Audit visually consistent with the compact production empty states used across the console. Empty audit lists should not render table column headers with a single empty row.

## 中文说明

本次增量处理管理审计列表的空态：没有审计事件时，不再显示审计表头和空行，而是直接展示紧凑空态。有审计事件时，原表格结构、业务标签和技术详情折叠区保持不变。

## Scope

- Frontend-only change.
- No backend API contract change.
- No audit event model or filtering behavior change.
- Existing non-empty audit table layout is preserved.

## Changes

- Moved the empty management audit list out of the table body.
- Added `management-audit-empty-state` and reused the shared compact empty-state styling.
- Added regression coverage to prevent `td colSpan={6}` from returning to the empty management audit path.
