# AgentHarbor 0.2.0 Management Local Write Visibility Plan

## Goal

Make successful Resource Management writes visible immediately in the workbench even when the follow-up console refresh fails or returns late.

## Design Consensus

- Keep management APIs unchanged.
- Treat API returned Agent and route-policy objects as authoritative for the specific changed row.
- Upsert returned Agent rows after create, status change, and credential rotation.
- Upsert returned route-policy rows after create and disable.
- Keep follow-up refresh feedback unchanged: success means fresh resource status; failure means the current workbench may be stale beyond the returned row.
- Keep the local merge logic in a pure helper so the management hook does not grow ad hoc list mutation logic.
