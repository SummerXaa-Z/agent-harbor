# 0.2.0 Management MCP App Error Data

Date: 2026-06-26
Branch: `codex/mcp-admin-lifecycle-conflict-coverage`

## Objective

Expose structured application error data from management MCP tool errors.

## 中文说明

AI Admin 通过 Management MCP 调用平台工具时，需要能稳定判断一次失败是输入冲突、权限不足、资源不存在，还是系统异常。此前 MCP JSON-RPC error 只包含通用 `code` 和自然语言 `message`，会丢失后端 `ADMIN_IDENTITY_DISABLED` 这类业务错误码。

本轮在 MCP tool error 中保留原有 `message`，并为 `domain.AppError` 增加 `error.data.appCode` 和 `error.data.httpStatus`。这样管理员 Agent 可以对已禁用管理员身份、权限边界、校验失败等结果做确定性分支，而不是解析自然语言。

## Scope

- Management MCP JSON-RPC error envelope.
- Managed administrator lifecycle MCP test coverage.
- Changelog and release checklist.
- No REST response, storage schema, frontend layout, or dependency changes.

## Changes

- Added optional `data` to management MCP JSON-RPC errors.
- Mapped `domain.AppError.Code` to `error.data.appCode`.
- Mapped `domain.AppError.Status` to `error.data.httpStatus`.
- Kept generic internal errors redacted as `internal server error` without structured app data.
- Extended `TestManagementMCPAdminIdentityTools` so disabled administrator key rotation and repeated disablement must return `ADMIN_IDENTITY_DISABLED` through MCP error data.
