# 0.2.0 Management MCP Explain Next Action Codes

Date: 2026-07-07
Branch: `codex/mcp-explain-next-action-codes`

## Objective

Make `explain_permission_package_draft` usable by admin agents without parsing human-readable `nextActions`.

## 中文说明

此前权限包草案解释已经包含策略门禁对象，但 management MCP 顶层仍只返回自然语言 `nextActions`。管理员 Agent 最常读取的是 explain 工具的顶层 summary 和 next action，因此本轮为 `explain_permission_package_draft` 增加顶层 `nextActionCodes`，同时保留旧版 `nextActions`。

## Codes

- `fix_draft_readiness`: required fields or unknown readiness warnings need operator input.
- `refresh_capabilities`: no matching allowed capability is available for the selected target.
- `narrow_data_scope`: requested region or data scope exceeds a capability boundary.
- `create_approval_request`: the draft is ready but policy gate requires approval before apply.
- `review_blocked_simulation_rows`: denied simulation rows are present and should remain blocked unless separately approved.
- `apply_permission_package`: the draft is ready for direct apply.

## Changes

- Added top-level `nextActionCodes` to `managementMCPExplainPermissionPackageResult`.
- Derived codes from draft readiness, readiness warnings, policy-gate codes, blocked simulation rows, and direct-apply readiness.
- Added backend assertions for blocked data-scope and approval-required explain paths.
- Added scenario coverage for the real management MCP explain call inside the permission package approval journey.
- Updated product docs and changelog in English and Simplified Chinese.
