# Management MCP Explain Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add read-only management MCP tools that explain permission-package readiness and capability access decisions.

**Architecture:** Keep REST and store behavior unchanged. Add explanation helpers inside `internal/httpapi/management_mcp.go` so the MCP surface can reuse existing package draft and capability access logic without adding persistence.

**Tech Stack:** Go HTTP API, existing in-memory/PostgreSQL repositories, MCP-style JSON-RPC over HTTP, Go tests.
