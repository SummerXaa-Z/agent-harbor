# 0.2.0 Management MCP Tool Safety Metadata

Date: 2026-07-07
Branch: `codex/management-mcp-tool-safety-metadata`

## Objective

Make management MCP `tools/list` safe for admin agents to consume by exposing machine-readable tool behavior metadata.

## 中文说明

此前 management MCP `tools/list` 只返回工具名称、说明和输入 schema。管理 Agent 能知道“怎么调用”，但不能稳定区分查询、规划和写入工具，也不能判断某个写入是否需要申请人、审批人或条件审批上下文。本轮为每个管理工具增加 `safety` 元数据，让 Agent 在执行前先按机器可读字段判断风险，而不是解析描述文案。

## Metadata

Each management tool now returns:

- `operationType`: `read`, `preview`, or `write`.
- `readOnly`: true when the tool does not mutate state.
- `mutatesState`: true when the tool can write control-plane state.
- `approvalMode`: `none`, `conditional`, `requester`, or `reviewer`.

## Changes

- Added `managementMCPToolSafety` and `managementMCPTool.safety`.
- Added centralized safety metadata injection for every management MCP tool.
- Marked draft and preflight tools as read-only `preview` operations.
- Marked apply as a mutating `write` operation with `conditional` approval context.
- Marked approval resolution tools with reviewer/requester approval modes.
- Added backend and scenario assertions so missing or `unspecified` metadata fails validation.
- Updated product docs and changelog in English and Simplified Chinese.
