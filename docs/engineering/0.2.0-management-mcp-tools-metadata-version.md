# 0.2.0 Management MCP Tools Metadata Version

Date: 2026-07-07
Branch: `codex/management-mcp-tools-metadata-version`

## Objective

Make the management MCP `tools/list` catalog self-describing for admin-agent clients by adding a stable metadata contract version.

## 中文说明

上一轮已经让 `tools/list` 为每个管理工具返回 `safety` 和 `access` 元数据。下一步需要给这组元数据一个稳定契约标记，否则外部 Agent 只能隐式假设字段结构永远不变。本轮在 `tools/list` 的顶层 result 返回 `metadataVersion: 1`，让客户端可以确认当前目录元数据契约，再决定是否允许自动写操作。

## Contract

The `tools/list` JSON-RPC result now includes:

- `metadataVersion: 1`
- `tools[].safety`
- `tools[].access`

Version `1` covers the current operation-safety and access-boundary metadata contract. Future incompatible catalog metadata changes should bump this value so admin-agent clients can pause automated write calls and require compatibility review.

## Changes

- Added `metadataVersion` to the management MCP `tools/list` result.
- Added backend regression coverage for the version marker.
- Extended the permission-package approval scenario to fail if the catalog version is missing or unexpected.
- Updated product docs and changelog in English and Simplified Chinese.
