# Management MCP Tools Implementation Plan

> **For agentic workers:** implement this plan task-by-task and keep each step verified before moving on.

**Goal:** Expose the v0.2.0 AI Admin permission journey through an Agent-friendly management MCP endpoint.

**Architecture:** Keep the existing REST management API as the source of truth. Add a management MCP JSON-RPC endpoint that supports `tools/list` and `tools/call`, reuses existing permission package and access-profile builders, and returns both MCP text content and structured content. This keeps UI and Agent-driven configuration on the same control-plane behavior.

**Tech Stack:** Go HTTP API, existing in-memory/PostgreSQL repositories, MCP-style JSON-RPC over HTTP.
