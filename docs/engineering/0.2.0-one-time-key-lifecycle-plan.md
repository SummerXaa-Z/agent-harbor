# AgentHarbor 0.2.0 One-Time Key Lifecycle Plan

## Goal

Make one-time Agent key material safe in the console: keep it visible after a successful key creation, but clear the plaintext when the operator closes the modal, changes the key form, dismisses it, or starts another key creation.

## Design Consensus

- Treat Agent key plaintext as short-lived sensitive UI state.
- Reuse the Admin Access pattern: show copy and clear actions next to the one-time key.
- Let action modals notify callers when they close, so sensitive child state can be cleared without coupling the modal component to management forms.
- Do not change backend key creation semantics; this increment only hardens the browser-side lifecycle of plaintext key material.
