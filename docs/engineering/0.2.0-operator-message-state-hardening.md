# 0.2.0 Operator Message State Hardening

Date: 2026-06-17

## Objective

Keep operator feedback in the production console localized and stable after language switches, refresh failures, and backend error fallbacks. Message state should store translation keys, parameters, or render callbacks instead of already-rendered strings, so old English or raw backend text does not remain in the Chinese UI.

## 中文说明

本次目标是收紧控制台操作反馈：访问查询、访问画像、能力治理、核心自检和资源管理操作不再把 `t(...)` 的结果直接写进 state。界面切换中英文时，旧消息会按当前语言重新渲染；中文主路径也不会直接展示英文后端错误。

## Scope

- Frontend-only change.
- No backend API contract change.
- No dependency change.
- Component props continue receiving plain strings; the descriptor state stays inside controllers/hooks and the AI Admin controller section.
- Existing management refresh-state types are unchanged; this increment focuses on primary operator messages and AI Admin inline status messages.
