# AgentHarbor 0.2.0 Permission Apply Refresh Feedback Plan

## Goal

Make Permission Changes report completed permission applications accurately even when the follow-up console data or tenant access profile refresh fails.

## Design Consensus

- Keep permission-package apply APIs unchanged.
- Save the returned application record immediately after apply succeeds.
- Merge returned capabilities and grant objects into `ConsoleData` before broader console refresh.
- Treat post-apply console/profile refresh failure as stale-view feedback, not as a failed permission application.
- Keep application health and go-live status checks best-effort after apply; their panels retain their own localized error messages.
