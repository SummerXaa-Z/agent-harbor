# 0.2.0 Permission Incomplete Next Action

Date: 2026-06-17

## Objective

Prevent operators from submitting an incomplete permission change for approval.

## 中文说明

权限变更页在草稿缺少租户、工作区、调用方、目标或访问对象等关键字段时，状态已经显示为“申请待补充”，但主路径下一步仍然显示“提交审批”。这会让管理员误以为可以进入审批，实际应该先完成配置。本次增量把缺配置状态的下一步改为“补全配置”，并让主按钮直接打开配置面板，不触发审批提交。

## Scope

- Frontend-only state, action routing, and copy change.
- No backend API change.
- No draft generation, approval, permission application, runtime validation, or go-live status semantics changed.
- Existing complete drafts still use “提交审批” as the next action.

## Changes

- Updated `resolvePermissionJourneyStatus` so `missingFields` or `needs_input` maps to `action.completePermissionRequest`.
- Updated the Permission Changes primary action handler so `action.completePermissionRequest` opens the configuration sheet.
- Renamed the bilingual action copy:
  - EN: `Complete configuration`
  - zh-CN: `补全配置`
- Added regression coverage for the journey-status branch, primary action routing, and Chinese action copy.
