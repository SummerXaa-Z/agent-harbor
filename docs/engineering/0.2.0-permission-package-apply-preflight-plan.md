# Permission Package Apply Preflight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only permission package apply preflight so admins and admin agents can verify blockers, warnings, planned changes, and approval readiness before any permission package is applied.

**Architecture:** The backend owns the source of truth by reusing the existing draft builder, policy gate, approval validator, data-scope fit check, and grant-chain repositories. The REST endpoint and Management MCP tool expose the same deterministic preflight response, while AI Admin uses it to guard live applies and show localized risk evidence.

**Tech Stack:** Go HTTP API, in-memory/Postgres repository interfaces through existing read methods, Management MCP JSON-RPC, React/TypeScript AI Admin UI, Bash scenario scripts.
