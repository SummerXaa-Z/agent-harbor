# Permission Package Approval Requests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal approval-request loop so approval-required permission packages can be reviewed and then applied with evidence.

**Architecture:** Add a first-class approval request domain record and repository methods, persist it in memory and PostgreSQL, then wire REST, MCP, and AI Admin through the same backend apply validation. Approval requests snapshot the permission package draft so apply can reject drift before writing entitlements or application records.

**Tech Stack:** Go domain/store/HTTP API, PostgreSQL migrations, management MCP JSON-RPC over HTTP, React/TypeScript frontend, Go tests, Node test runner.
