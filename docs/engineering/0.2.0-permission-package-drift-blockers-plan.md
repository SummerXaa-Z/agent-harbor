# 0.2.0 Permission Package Drift Blockers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development when callable, otherwise use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make permission-package application impact review production-usable when recorded grants drift, are disabled, or are missing by returning stable blocker codes and rendering localized blocker guidance in AI Admin.

**Architecture:** Keep the existing read-only impact endpoint and remediation plan. Add additive `blockerCodes` arrays to `rollbackReview` and `remediationPlan` while preserving existing `blockers` text for compatibility. UI should prefer translated blocker codes and fall back to raw blocker text.

**Tech Stack:** Go HTTP API, in-memory repository tests, React + TypeScript frontend, i18n dictionaries, local scenario script, README/product docs/changelog.
