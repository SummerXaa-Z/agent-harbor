# Permission Package Policy Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic policy gate that allows low-risk permission packages to apply directly and blocks higher-risk packages until an approval workflow exists.

**Architecture:** Extend the permission package draft domain with `policyGate`, evaluate policy inside `internal/permissionpack`, and enforce the gate in the shared REST/MCP apply path. Surface the same gate in MCP explanations and the AI Admin UI, with the frontend local draft builder mirroring backend rules for offline demo compatibility.

**Tech Stack:** Go domain and HTTP API, deterministic permission package builder, management MCP JSON-RPC over HTTP, React/TypeScript frontend, Go tests, Node test runner.
