# 0.2.0 Policy Empty State Compact

Date: 2026-06-17

## Objective

Keep Access Policy and Route Policy empty states consistent with the Resource Management empty-state treatment. When no policies exist, operators should see a compact setup prompt instead of a table header with an empty row.

## 中文说明

本次增量处理访问策略/路由策略列表的空态：此前无策略时仍然渲染完整表格，再在表格内部放一个空行，视觉上像“表格坏了”。现在无策略时直接展示紧凑空态，有策略时保留原表格。

## Scope

- Frontend-only change.
- No backend API contract change.
- No route policy model or mutation behavior change.
- Existing non-empty policy table layout is preserved.

## Changes

- Updated `PolicyTable` to return a standalone empty state when `policies.length === 0`.
- Removed the table-internal empty row treatment.
- Added `policy-empty-state` styling aligned with Resource Management empty states.
- Added regression coverage to prevent table chrome returning to the empty policy path.
