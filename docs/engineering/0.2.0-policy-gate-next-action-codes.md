# 0.2.0 Policy Gate Next Action Codes

Date: 2026-07-06
Branch: `codex/policy-gate-next-action-codes`

## Objective

Make permission-package draft policy gates machine-readable by adding stable next-action codes for approval-required drafts while preserving the existing human-readable `nextActions` field.

## 中文说明

上一轮已经让应用前预检返回 `nextActionCodes`。但更早一步的草案解释和策略门禁仍只有自然语言 `nextActions`，管理 Agent 在 `draft_permission_package` 或 `explain_permission_package_draft` 阶段仍需要解析英文提示才能知道下一步是创建审批请求。

本轮为 `PermissionPackagePolicyGate` 增加 `nextActionCodes`：

- 当前需审批策略门禁返回 `create_approval_request`。
- 旧版 `nextActions` 继续保留，现有调用方不会被破坏。
- 后端真实草案、management MCP explain 结构化响应、内存仓库克隆和前端本地模板保持一致。

## Changes

- Added `PermissionPackagePolicyNextActionCode` and `PermissionPackagePolicyGate.nextActionCodes`.
- Set `create_approval_request` when policy-gate reasons require approval.
- Copied policy-gate next-action codes in the in-memory store clone path.
- Added backend assertions for permission package draft and management MCP explain responses.
- Updated frontend permission package types and local fallback draft builder.
- Updated product docs and changelog in English and Simplified Chinese.
