# 0.2.0 Policy Gate Presenter Code Fallback

Date: 2026-07-06
Branch: `codex/policy-gate-code-presenters`

## Objective

Keep permission-package policy-gate guidance localized and machine-readable in the web console by preferring stable policy-gate `nextActionCodes` over backend prose.

## 中文说明

上一轮后端已经让权限包策略门禁返回 `nextActionCodes`。本轮把 Web 控制台的策略门禁提示也收进 `permissionWorkbenchPresenters.ts`，并优先使用 `create_approval_request` 代码渲染本地化下一步提示。这样中文界面不会因为后端返回英文 `nextActions` 而泄漏技术文案，后续新增代码也可以集中扩展 presenter。

## Changes

- Added `permissionPolicyGateNextActionByCode` and exported `permissionPolicyGateMessages`.
- Moved policy-gate message composition out of `ConsoleController.tsx`.
- Added EN and zh-CN copy for policy-gate next actions.
- Added regression coverage that policy-gate presenter fallbacks do not render backend `nextActions`.
- Added memory-store regression coverage that cloned approval requests preserve policy-gate `nextActionCodes`.
- Updated product docs and changelog in English and Simplified Chinese.
