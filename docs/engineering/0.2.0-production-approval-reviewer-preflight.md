# 0.2.0 Production Approval Reviewer Preflight

Date: 2026-06-25
Branch: `codex/production-approval-reviewer-preflight`

## Objective

Validate configured approval reviewer routing during production deployment preflight, before AgentHarbor initializes PostgreSQL storage.

## 中文说明

`AGENT_HARBOR_APPROVAL_REVIEWERS` 控制权限包审批请求能被哪些审批人处理。它仍然是可选配置，避免阻断小团队或单管理员部署；但只要生产环境显式配置了审批人路由，系统必须在启动早期确认格式可解析。否则权限变更可能启动后才发现审批队列不可达或审批人范围配置错误。

## Scope

- Backend production deployment preflight.
- Shared approval reviewer parsing for preflight and runtime configuration.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering note.
- No API route, frontend, storage schema, or dependency changes.
- Development-mode behavior remains compatible.

## Changes

- `deploymentEnvFromOS` now includes `AGENT_HARBOR_APPROVAL_REVIEWERS` so pure production preflight can inspect reviewer routing.
- Approval reviewer parsing now flows through `approvalReviewersFromRaw`, keeping production preflight and runtime startup on the same validation rules.
- Production mode now adds a blocking `approval_reviewers_valid` check.
- Malformed configured reviewer scopes fail before PostgreSQL connection, migration, or credential handling.
- `scenario-production-hardening.sh` now verifies malformed approval reviewer routing fails before an intentionally invalid PostgreSQL URL can be parsed or connected.
- README, `.env.example`, release checklist, and changelog describe the stricter production startup contract.

## Notes

This check validates only configuration syntax. It does not require reviewer routing to be configured in production, and it does not verify external identity-provider membership. Authenticated reviewer identity binding remains enforced by `AGENT_HARBOR_ADMIN_IDENTITIES` and the approval API at request time.
