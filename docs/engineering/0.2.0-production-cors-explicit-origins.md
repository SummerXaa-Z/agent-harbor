# 0.2.0 Production CORS Explicit Origins

Date: 2026-06-17
Branch: `codex/production-cors-explicit-origins`

## Objective

Make production deployment CORS fail closed unless browser origins are explicitly configured.

## 中文说明

旧逻辑在所有模式下都会默认放行本地开发控制台来源，例如 `http://127.0.0.1:5174`。这对本地开发友好，但在 `AGENT_HARBOR_DEPLOYMENT_MODE=production` 下会让生产 API 保留开发期浏览器来源。现在生产模式只信任 `AGENT_HARBOR_CORS_ORIGINS` 中显式列出的来源；开发模式仍保留默认本地来源，并允许通过同一个变量追加隔离测试端口。

## Scope

- Backend startup/runtime CORS policy.
- No API route contract changes.
- No frontend changes.
- No new dependencies.

## Changes

- Added an HTTP API option for enabling or disabling default local CORS origins.
- Kept default local CORS origins enabled for development mode.
- Disabled default local CORS origins when `AGENT_HARBOR_DEPLOYMENT_MODE=production`.
- Kept explicit `AGENT_HARBOR_CORS_ORIGINS` honored in both development and production modes.
- Documented the production behavior in README runtime configuration.
