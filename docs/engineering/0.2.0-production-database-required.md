# 0.2.0 Production Database Required

Date: 2026-06-23
Branch: `codex/production-database-required`

## Objective

Require persistent PostgreSQL storage before AgentHarbor starts in production mode.

## 中文说明

AgentHarbor 的租户、授权链、Agent 凭据、管理员身份和审计记录都是生产控制面状态。开发模式可以使用内存仓库降低本地试用门槛，但生产模式如果允许内存仓库启动，服务重启后会丢失权限配置和审计上下文。本轮把缺失 `AGENT_HARBOR_DATABASE_URL` 从 warning 升级为 production blocking preflight，让生产进程在触碰存储初始化前直接失败。

## Scope

- Backend production deployment preflight.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering notes.
- No API route, frontend, storage schema, or dependency changes.
- Development-mode behavior remains compatible.

## Changes

- `persistent_storage_configured` is now a production blocking check instead of a warning.
- Production mode now rejects startup when `AGENT_HARBOR_DATABASE_URL` is missing.
- Existing preflight-before-storage ordering remains intact: other blocking production configuration errors still fail before PostgreSQL connection attempts.
- `scenario-production-hardening.sh` now verifies the missing-database startup failure instead of expecting a safe production in-memory startup.
- Documentation now states that the in-memory repository is for development or local evaluation only.
