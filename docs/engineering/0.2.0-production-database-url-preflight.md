# 0.2.0 Production Database URL Preflight

Date: 2026-06-25
Branch: `codex/production-database-url-preflight`

## Objective

Validate production PostgreSQL connection strings before AgentHarbor initializes storage, without leaking connection credentials in startup errors.

## 中文说明

生产模式已经要求配置 `AGENT_HARBOR_DATABASE_URL`。如果连接串格式错误，系统应该在 deployment preflight 阶段给出明确、脱敏的配置错误，而不是进入 PostgreSQL 初始化路径后才由连接层返回 `connect postgres` 错误。本轮把数据库连接串解析校验纳入纯生产预检，并确保错误消息只说明环境变量无效，不回显包含用户名、密码或主机的原始连接串。

## Scope

- Backend production deployment preflight.
- Startup ordering before PostgreSQL pool construction and migration.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering notes.
- No API route, frontend, storage schema, or dependency changes.
- Development-mode in-memory behavior remains compatible.

## Changes

- Production mode now adds a blocking `database_url_valid` check when `AGENT_HARBOR_DATABASE_URL` is configured.
- Invalid production database URLs fail in `deploymentConfigPreflightFromEnv` before `pgxpool.New` is called.
- Database URL preflight errors are fixed, redacted messages that do not include the raw connection string or password.
- `scenario-production-hardening.sh` now verifies invalid production database URLs fail before PostgreSQL initialization and do not leak credentials.
- README, `.env.example`, release checklist, and changelog now describe the stricter production startup contract.
