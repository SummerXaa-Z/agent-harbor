# Production Evidence Report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only JSON evidence report for the v0.2.0 AI Admin permission-package production readiness journey.

**Architecture:** Reuse the existing production readiness aggregation as the source of truth, then project a bounded report shape for REST, management MCP, AI Admin export, and scenario validation. The report carries evidence references rather than raw unbounded trace or audit dumps.

**Tech Stack:** Go HTTP API, management MCP JSON-RPC over HTTP, React/TypeScript frontend, shell scenario verification, Go tests, Node frontend tests.

---
