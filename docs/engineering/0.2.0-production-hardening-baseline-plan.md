# 0.2.0 Production Hardening Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development when explicitly authorized; otherwise use superpowers:executing-plans or inline execution to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a production-safety baseline gate that proves AgentHarbor starts with conservative security defaults before any release-readiness claim.

**Architecture:** Keep the existing API implementation unchanged unless the gate exposes a defect. Add a local scenario script that starts the API with `AGENT_HARBOR_ADMIN_KEY` set and private upstreams disabled, then verifies management authorization, permission-package authorization, management MCP authorization, and default private-upstream rejection. Wire the script into Makefile and release documentation so production hardening becomes repeatable.

**Tech Stack:** Go HTTP API, Bash scenario scripts, curl, Python JSON assertions, Makefile release gates.
