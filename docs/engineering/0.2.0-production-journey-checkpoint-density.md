# 0.2.0 Production Journey Checkpoint Density

Date: 2026-06-17

## Objective

Reduce the first-viewport weight of the production journey checkpoint while preserving persistent journey context and the next safe action.

## 中文说明

生产路径提示需要常驻，让管理员知道自己处在“开始配置 -> 资源接入 -> 访问查询 -> 权限变更 -> 上线状态 -> 交接”的哪一步。但它不应该像一个流程 Demo 卡片占据过多首屏高度。本次增量把宽屏布局从两行流程卡改成三段同排的上下文条：当前动作、阶段列表、下一步入口仍然完整保留，但整体高度显著降低。

## Scope

- Frontend-only CSS and regression-test change.
- No backend API contract change.
- No production journey model, stage order, next-action hash, routing, or accessibility semantics change.
- Mobile/narrow layouts continue to fall back to a single-column layout.

## Changes

- Changed `.production-journey-checkpoint` wide layout to three columns: current action, stage list, next action.
- Removed the forced full-row placement from `.production-journey-steps`.
- Reduced checkpoint padding and set a compact 48px minimum height.
- Kept `aria-current="step"` and the model-driven stage rendering unchanged.
- Added regression coverage so the checkpoint remains compact and does not reintroduce the full-row stage layout.
