# 0.2.0 Production Journey Checkpoint Layout

Date: 2026-06-17

## Objective

Make the global production journey checkpoint behave like a lightweight status bar across Resource Management, Access Query, Permission Changes, and Go-Live Status. The checkpoint should preserve context and the next safe action without compressing the main workbench.

## 中文说明

本次增量收束全局生产路径提示：它仍然常驻展示当前阶段和下一步动作，但不再把标题、六个阶段和按钮挤在同一行，避免在侧边栏布局和较窄内容区中打断主任务。

## Scope

- Frontend-only change.
- No backend API contract change.
- No production journey state-machine change.
- No dependency change.
- Existing route hashes and next-action behavior are preserved.

## Changes

- Convert the checkpoint from a three-column compressed row into a two-line layout.
- Keep the current next action and CTA in the first row.
- Move the stage list into a wrapping progress row, so long localized labels do not squeeze the page.
- Add `aria-current="step"` for the current stage.
- Add regression tests for the wrapping stage layout and accessibility marker.
