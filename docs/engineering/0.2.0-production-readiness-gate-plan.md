# Production Readiness Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only production readiness gate for the v0.2.0 AI Admin permission-package journey.

**Architecture:** Reuse the existing permission-package preflight, application listing, impact review, tenant access profile, trace listing, and audit listing paths. Expose one REST endpoint and one management MCP tool that return the same deterministic response, then render that result in AI Admin with bilingual labels.

**Tech Stack:** Go HTTP API, in-memory and PostgreSQL repositories through existing interfaces, management MCP JSON-RPC over HTTP, React/TypeScript frontend, shell scenario verification, Go tests, Node frontend tests.

---

```go
func TestPermissionPackageProductionReadinessBlocksBeforeApplyAndReadyAfterEvidence(t *testing.T) {
	repo := store.NewMemory()
	router := newRouterWithRepo(repo)
	input, target, caller, writeCapability, approvalRequestID := createApprovedSupportPermissionPackageFixture(t, router)

	before := decodeData[permissionPackageProductionReadinessResponse](t, request(t, router, http.MethodGet, "/api/v1/permission-packages/production-readiness?tenantId=tenant-root&workspaceId=ws-sales&templateId=support-ticket-triage&targetId="+target.ID+"&callerInstanceId="+caller.ID+"&subjectId=user:support-001", nil, ""))
	if before.Status != "blocked" || !productionReadinessHasCheck(before.Checks, "application_present", "blocking") {
		t.Fatalf("expected readiness to block before apply, got %#v", before)
	}

	applied := decodeData[permissionPackageApplyResponse](t, request(t, router, http.MethodPost, "/api/v1/permission-packages:apply", map[string]any{
		"tenantId":          input["tenantId"],
		"workspaceId":       input["workspaceId"],
		"callerInstanceId":  input["callerInstanceId"],
		"targetId":          input["targetId"],
		"templateId":        input["templateId"],
		"requestText":       input["requestText"],
		"region":            input["region"],
		"subjectSelector":   input["subjectSelector"],
		"approvalRequestId": approvalRequestID,
	}, ""))
	appendProductionReadinessTrace(t, repo, domain.TraceDecisionDenied, caller.ID, target.ID, "", "export_contracts", "user:support-001")
	appendProductionReadinessTrace(t, repo, domain.TraceDecisionAllowed, caller.ID, target.ID, writeCapability.ID, writeCapability.Key, "user:support-001")

	after := decodeData[permissionPackageProductionReadinessResponse](t, request(t, router, http.MethodGet, "/api/v1/permission-packages/production-readiness?tenantId=tenant-root&workspaceId=ws-sales&templateId=support-ticket-triage&targetId="+target.ID+"&callerInstanceId="+caller.ID+"&subjectId=user:support-001", nil, ""))
	if after.Status != "ready" || after.LatestApplication == nil || after.LatestApplication.ID != applied.Application.ID {
		t.Fatalf("expected readiness after evidence, got %#v", after)
	}
	if !productionReadinessHasCheck(after.Checks, "runtime_allowed_trace_present", "passed") ||
		!productionReadinessHasCheck(after.Checks, "runtime_denied_trace_present", "passed") ||
		!productionReadinessHasCheck(after.Checks, "applied_audit_event_present", "passed") {
		t.Fatalf("expected runtime and audit evidence checks to pass, got %#v", after.Checks)
	}
}
```

```go
	ApplicationHealth *permissionPackageApplicationHealthEntry
	ApplicationImpact *permissionPackageApplicationImpactResponse
	AccessProfile     *tenantAccessProfileResponse

}
```

Add route in `internal/httpapi/server.go` before application-specific routes:

Implement query parsing and helper functions in `internal/httpapi/server.go`. The helper should:

- validate required `tenantId`, `workspaceId`, `templateId`, `targetId`, `callerInstanceId`
- list latest matching application with limit `1`

- call `preflightPermissionPackageRequest`
- call `permissionPackageApplicationImpact` for the latest application
- call `buildTenantAccessProfile` with `TraceLimit`
- list traces for caller and target, then select latest allowed and denied traces, respecting `subjectId` when supplied
- list audit events for `permission_package.applied` and selected application id
- return stable checks and `ready`, `needs_review`, or `blocked`
