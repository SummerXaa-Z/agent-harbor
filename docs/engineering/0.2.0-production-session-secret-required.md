# 0.2.0 Production Session Secret Required

Date: 2026-06-23
Branch: `codex/production-session-secret-required`

## Objective

Require an explicit high-entropy web-console session signing secret before AgentHarbor starts in production mode.

## 中文说明

Web 控制台会把管理员认证结果换成 HttpOnly session cookie。之前生产模式缺少 `AGENT_HARBOR_SESSION_SECRET` 时只给 warning，服务端会从已配置的管理员凭据派生会话签名密钥。这个默认值虽然能保持会话稳定，但会让“管理 API key 的知情范围”和“cookie 签名密钥的知情范围”发生重叠。生产环境应当把会话签名密钥作为独立 secret 管理，因此本轮把缺失 `AGENT_HARBOR_SESSION_SECRET` 升级为生产启动阻断。

## Scope

- Backend production deployment preflight.
- Production hardening scenario coverage.
- Runtime configuration docs, changelog, release checklist, and engineering notes.
- No API route, frontend, storage schema, or dependency changes.
- Development-mode behavior remains compatible.

## Changes

- `session_secret_explicit` is now a production blocking check instead of a warning.
- Production mode now rejects startup when `AGENT_HARBOR_SESSION_SECRET` is missing.
- Existing `session_secret_strength` behavior remains unchanged: explicit production secrets must be at least 32 characters and not a common weak value.
- `scenario-production-hardening.sh` now verifies the missing-session-secret startup failure before the weak-session-secret failure.
- Documentation now states that `AGENT_HARBOR_SESSION_SECRET` is optional only in development and required in production.
