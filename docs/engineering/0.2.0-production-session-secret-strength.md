# 0.2.0 Production Session Secret Strength

Date: 2026-06-23
Branch: `codex/production-session-secret-strength`

## Objective

Block explicitly configured weak web-console session signing secrets before a production-mode AgentHarbor process starts.

## 中文说明

`AGENT_HARBOR_SESSION_SECRET` 用于签名 Web 控制台的 HttpOnly 会话 Cookie。生产模式下不设置该变量仍保持 warning，因为系统可以从已配置管理员凭据派生稳定密钥；但如果部署者显式设置了 `secret`、`password` 或很短的值，说明他们想控制会话签名密钥，此时继续启动会把控制台登录保护建立在弱密钥上。本轮把显式弱会话密钥升级为生产启动阻断。

## Scope

- Backend deployment preflight model.
- Production-mode explicit `AGENT_HARBOR_SESSION_SECRET` strength validation.
- README, `.env.example`, changelog, and engineering documentation.
- No API route contract changes.
- No frontend changes or new dependencies.

## Changes

- Added `session_secret_strength` as a production blocking preflight check when `AGENT_HARBOR_SESSION_SECRET` is explicitly configured.
- Production mode now rejects explicit session secrets shorter than 32 characters.
- Production mode rejects common weak explicit values such as `secret`, `password`, `admin`, `changeme`, and `test`.
- Added a production-hardening scenario assertion for weak explicit session secrets.
- Kept the existing missing-session-secret production warning unchanged.
