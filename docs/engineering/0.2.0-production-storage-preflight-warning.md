# 0.2.0 Production Storage Preflight Warning

Date: 2026-06-17
Branch: `codex/production-storage-preflight-warning`

## Objective

Make production-mode startup visibly warn when AgentHarbor is running without persistent database storage.

## 中文说明

权限平台的租户、Agent、授权、凭据和审计记录不能在生产中依赖内存仓库。本轮先把缺少 `AGENT_HARBOR_DATABASE_URL` 纳入生产部署预检 warning，并在启动时输出结构化 warning 日志。后续 `docs/engineering/0.2.0-production-database-required.md` 已进一步把生产缺失持久化数据库升级为启动阻断。

## Scope

- Backend deployment preflight model.
- Startup logging for warning-level deployment checks.
- Production hardening scenario assertion.
- No API route contract changes.
- No frontend changes or new dependencies.

## Changes

- Added `AGENT_HARBOR_DATABASE_URL` to deployment preflight input.
- Added `persistent_storage_configured` production check:
  - `warning` when production mode uses the in-memory repository.
  - `passed` when a database URL is configured.
- Added structured warning logs for warning-level deployment checks.
- Updated `scenario-production-hardening.sh` to assert the production safe-minimal startup emits the persistent-storage warning.
- Documented the production storage warning in README runtime configuration.
