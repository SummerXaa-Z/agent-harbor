# 0.2.0 Resource Advanced Details Collapse

Date: 2026-06-17

## Objective

Keep Resource Management focused on the operator's primary task: add or repair resources, keep the selected resource context visible, and follow the recommended next action. The lower Agent registry and contract matrix remain available for troubleshooting, but no longer compete with the main workbench on first view.

## 中文说明

本次增量把资源管理页底部的 Agent 注册表和契约矩阵收进“高级资源明细”。默认界面只保留资源工作台和明确的次级明细入口，避免管理员刚进入页面就被对象清单和底层矩阵打断。

## Scope

- Frontend-only change.
- No backend API contract change.
- No resource data model change.
- No new dependency.
- Existing Agent table filtering, detail view, status actions, and contract matrix content are preserved after expanding the details section.

## Changes

- Wrap the Agent registry and contract matrix in a native `details` disclosure inside `RegistryView`.
- Add bilingual copy for the Advanced resource details entry.
- Style the disclosure as a compact secondary action area with a clear button-like affordance.
- Add regression tests so Resource Management cannot silently return to a flat, table-heavy layout.
