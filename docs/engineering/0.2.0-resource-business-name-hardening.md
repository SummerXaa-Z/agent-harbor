# 0.2.0 Resource Business Name Hardening

Date: 2026-06-17

## Objective

Keep generated scenario identifiers out of the primary resource path. Operators should see business-readable resource names first, while raw run identifiers remain secondary technical context.

## 中文说明

本次增量处理资源管理、访问查询和权限变更中 MCP 能力治理场景的资源名：`MCP Capability ... checkpoint-layout-...` 这类自动生成名称不再作为主标题展示，而是转换为“客服助手”“工单工具服务”等业务标签。

## Scope

- Frontend-only change.
- No backend API contract change.
- No resource lifecycle state change.
- No dependency change.
- Existing user-provided custom names are preserved.

## Changes

- Add business labels for MCP capability governance caller and target resources.
- Normalize generated `MCP Capability Caller ...` and `MCP Capability MCP Target ...` names through both presenter paths used by resource/access/permission views.
- Replace visible Resource Management lifecycle wording with resource status and resource configuration wording.
- Add tests to ensure both presenter paths keep the scenario labels readable.
