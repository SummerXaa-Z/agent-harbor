# 0.2.0 Resource Command Modal Polish

Date: 2026-06-17

## Objective

Make Resource Management commands look and behave like production B2B operations instead of inline demo cards.

## 中文说明

资源管理页已经把 Agent、MCP 工具服务、凭据、能力和策略收束到同一个工作台，但资源命令区仍容易被理解成一排同级工具按钮；弹窗表单也保留了内层卡片边框，视觉上像“卡片里再塞卡片”。本次增量把“创建 Agent”明确为主操作，把密钥、凭据和策略放在维护操作组，并让操作弹窗使用独立表单表面，减少视觉噪音。

## Scope

- Frontend-only structure and visual-system change.
- No backend API change.
- No new dependency.
- No i18n key change; existing bilingual copy is reused.
- No resource creation, key creation, credential rotation, or route-policy semantics changed.

## Changes

- Split Resource Management command actions into `resource-lifecycle-command-primary` and `resource-lifecycle-maintenance-actions`.
- Kept Create Agent as the primary command and grouped create-key, rotate-credential, and create-policy as secondary maintenance commands.
- Made secondary command buttons more clearly clickable with brand-border hover treatment while keeping only the primary action filled.
- Widened command dialogs from 680px to 720px for dense operational forms.
- Removed the inner card treatment from forms inside command dialogs so modal forms render as standalone dialog content.
- Added responsive handling so the maintenance action divider disappears on narrow viewports.
