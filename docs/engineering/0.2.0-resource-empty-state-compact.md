# 0.2.0 Resource Empty State Compact

Date: 2026-06-17

## Objective

Make Resource Management feel like a production setup workflow when no resources exist. An empty system should show a compact setup prompt, not an empty table with column headers and no rows.

## 中文说明

本次增量处理资源管理页的空资源清单：此前无资源时仍然保留表格列头，用户会看到一个空表格，而不是明确的下一步。现在无资源时隐藏列头，展示紧凑空态，并用文案提示通过上方操作按钮注册调用方或 MCP 工具服务。

## Scope

- Frontend-only change.
- No backend API contract change.
- No resource lifecycle model change.
- Existing non-empty resource list layout is preserved.

## Changes

- Added `hasResources` gating to `ResourceLifecycleView`.
- Render resource list column headers only when there are resources.
- Added a compact `resource-lifecycle-empty` container for the zero-resource state.
- Tightened the advanced Agent registry empty-state height.
- Updated bilingual resource empty-state guidance copy.
- Added regression coverage for the empty resource list structure and copy.
