# 0.2.0 Resource Lifecycle Empty Guidance

Date: 2026-06-17

## Objective

Make an empty Resource Management workspace tell first-time operators the next safe action without reintroducing a duplicate empty card.

## 中文说明

资源生命周期工作台没有资源时，过去只剩指标、阶段和操作按钮，用户能操作但不一定知道当前状态。直接加一张空卡会让页面重新变成 Demo 式堆叠。本次增量把“暂无受管资源”的提示放进现有操作中心，作为紧凑的行内说明：状态清楚，下一步清楚，但不制造新的主卡片。

## Scope

- Frontend-only layout and copy placement change.
- No backend API contract change.
- No routing, resource lifecycle model, modal, or data-loading behavior change.
- No new i18n keys; the inline guidance reuses existing English and Simplified Chinese `resource.empty.*` translations.

## Changes

- Added a compact `resource-lifecycle-empty-guidance` note inside the existing operation center when no managed resources exist.
- Kept the resource list hidden when there are no resources.
- Kept the previous guard against `EmptyRow`, `actionHash="#getting-started"`, and empty list table treatment.
- Added style regression coverage for the inline guidance.

- Browser DOM verification on `http://127.0.0.1:15184/#registry`: empty live system rendered the inline guidance, did not render `.resource-lifecycle-list`, did not render `.empty-row` inside the lifecycle workspace, and showed all five lifecycle metrics as `0`.
- `pnpm --dir frontend test`: passed, 294/294.
- `pnpm --dir frontend build`: passed with the existing Vite chunk-size warning.
- `make check`: passed.
- `make release-check`: passed, including production hardening, web console production journey, admin tenant boundary, admin access management, and tenant permission center scenarios.

## Notes

- This keeps the product direction from earlier UI reviews: no standalone duplicate empty cards, but first-time users still get a clear state and next action.
