# 0.2.0 Resource Management Workbench Balance

Date: 2026-06-17

## Objective

Make the resource management advanced maintenance area read as one coherent workbench instead of two disconnected cards.

## 中文说明

资源管理页的主路径已经集中在“资源生命周期”工作台里，但高级维护区展开后，Agent 注册表和契约矩阵仍然像两个散落的卡片。这个区域只应该在排查、批量核对或审计复核时打开，因此视觉上要更像一个统一的维护抽屉，而不是新的主工作区。

## Scope

- Frontend-only layout and density change.
- No backend API contract change.
- No routing, modal, lifecycle action, or data-loading behavior change.
- No new i18n keys; all visible copy continues to use existing bilingual translation entries.

## Changes

- Changed the advanced maintenance area from an 8/4 split to a 7/5 split so the registry and contract matrix feel balanced on wide screens.
- Tightened the advanced grid spacing and added a subtle maintenance-area background.
- Removed card shadow from panels inside the advanced area so they read as sections inside one drawer.
- Reduced nested panel header height inside the advanced area.
- Added style regression coverage for the new balance and anti-shadow treatment.

## Notes

- This is intentionally a visual hierarchy change only. Resource creation, credential rotation, access query handoff, and lifecycle actions stay unchanged.
