# 0.2.0 Resource Management Workbench Visual Tightening

Date: 2026-06-17

## Objective

Make Resource Management feel like a focused production workbench instead of a collection of demo cards. Operators should see one resource-management entry, clear action buttons, a persistent selected-resource context, and a readable resource list without lifecycle jargon on the primary path.

## 中文说明

本次增量收束资源管理页的视觉和用词：主路径不再把“资源生命周期”作为用户可见标题，而是表达为“资源管理”。页面保留当前资源上下文和推荐下一步，同时让创建 Agent、创建密钥、轮换凭据和创建策略更像明确的操作按钮，而不是卡片入口。

## Scope

- Frontend-only change.
- No backend API contract change.
- No dependency change.
- Existing resource action modal behavior is preserved.
- Existing resource action planner and safe prefill behavior are preserved.

## Changes

- Rename the primary visible panel from Resource Lifecycle / 资源生命周期 to Resource Management / 资源管理.
- Add a resource-list title and resource count so the list reads as an intentional section.
- Reduce nested card treatment in the operation area, refresh state, selected-resource context, and list.
- Make command action triggers look like operation buttons; the secondary "open" affordance is reduced to an icon-only cue.
- Keep bilingual copy paired for all new resource-list text.
- Add regression tests for the resource-list title, list count, and command-button visual contract.
