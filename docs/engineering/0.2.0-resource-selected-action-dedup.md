# 0.2.0 Resource Selected Action Deduplication

Date: 2026-06-17

## Objective

Reduce duplicate action entry points on the Resource Management workspace. When a resource is selected, the recommended operation should live in the context panel, while the selected list row should only indicate which resource is in focus.

## 中文说明

本次增量继续收束资源管理页：当用户选中某个资源时，右侧上下文面板已经展示了“推荐下一步”。列表行如果再显示同一个操作按钮，会让管理员误以为存在两条不同动作，也增加误触风险。因此选中行改为显示“当前关注”，实际操作入口保留在上下文面板。

## Scope

- Frontend-only change.
- No backend API contract change.
- No resource status, summary, filtering, or action-planning behavior change.
- Only selected resource rows suppress their duplicate row-level action; non-selected rows keep their direct action shortcut.

## Changes

- `ResourceLifecycleRow` now renders a localized selected-state label for the active row.
- The context panel remains the authoritative action surface for the selected resource.
- Added bilingual copy for the selected row label.
- Added style and i18n regression coverage so the duplicate selected-row action does not return.
