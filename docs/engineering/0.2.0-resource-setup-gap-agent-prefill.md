# 0.2.0 Resource Setup Gap Agent Prefill

Date: 2026-06-17
Branch: `codex/resource-gap-agent-prefill`

## Objective

Make Resource Management setup-gap actions more production-usable by opening the Create Agent dialog with a safe draft that matches the missing setup item.

## 中文说明

上一轮已经让“访问查询准备度”缺口可以直接打开“创建 Agent”。本轮继续收束体验：缺调用方时预填本地调用方 Agent；缺目标服务时预填 MCP 服务 Agent。这样管理员不需要先理解底层通道类型，再决定该填什么。

## Scope

- No backend changes.
- No new dependencies.
- No changes to tenant or workspace scope resolution.
- Do not prefill endpoint, credential header, credential key, or secret value.
- Keep English and Simplified Chinese copy paired.

## Changes

- `ResourceLifecycleView` now reports the setup-gap kind when launching the Create Agent action.
- `resourceSetupGapAgentDraft` maps `caller` gaps to an active local caller Agent draft.
- `resourceSetupGapAgentDraft` maps `target` gaps to an active MCP target Agent draft.
- `ConsoleController` applies the generated draft before opening the existing Create Agent dialog.
- The generated draft fills only name, channel, status, retry defaults, and description.
- Bilingual defaults were added for caller and target Agent names and descriptions.
- Unit tests now guard both caller and target drafts, including that setup-gap prefill does not carry endpoint or credential fields.
