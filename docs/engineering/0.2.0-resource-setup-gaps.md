# 0.2.0 Resource Setup Gaps

Date: 2026-06-17

## Objective

Make Resource Management explain which resource prerequisites still block Access Query after operators follow the setup blocker from the query workspace.

## 中文说明

访问查询已经会在缺资源或缺能力时引导管理员进入资源管理或工具能力，但资源管理落点本身还需要回答“我来到这里后具体缺什么”。本次增量在已有部分资源但访问查询仍无法闭合时展示“访问查询准备度”缺口：缺调用方 Agent 时提示使用上方创建 Agent；缺目标服务时提示注册可暴露工具的 Agent；缺工具能力时提供跳转到工具能力页面的真实链接。

## Scope

- Frontend-only resource lifecycle model and UI change.
- No backend API change.
- No new dependency.
- No resource mutation behavior change.
- No automatic form submission.
- All new visible copy is bilingual.

## Changes

- Added `ResourceLifecycleSetupGap` to the resource lifecycle summary.
- Detects missing active caller Agent, missing active target service, and missing target tool capabilities from existing console data.
- Renders setup gaps inside the Resource Management command center only when at least one resource already exists and Access Query prerequisites are still incomplete.
- Keeps same-page Create Agent guidance as non-clickable text so it does not look like a fake navigation action.
- Keeps Tool Capabilities as a real link to `#capabilities` when missing capabilities are the next prerequisite.
- Added responsive styling for the gap panel and individual gap items.
