# 0.2.0 Self-Check Disclosure Affordance

Date: 2026-06-17

## Objective

Make System Self-Check feel like a production diagnostic workflow instead of a form-heavy demo page. Optional settings and runtime details should remain available, but their closed state must look like an intentional secondary action.

## 中文说明

本次增量只调整系统自检页的折叠入口视觉：高级配置和运行明细默认仍然收起，但右侧增加明确的“查看详情”操作区和旋转箭头。这样用户能看出这里可以展开，而不会误以为表单又直接挂在主路径上。

## Scope

- Frontend-only change.
- No backend API contract change.
- No self-check execution logic change.
- No default configuration or runtime data change.
- No new dependency.

## Changes

- Add an explicit disclosure action to the System Self-Check advanced settings section.
- Add the same disclosure action to runtime details for consistency.
- Style both actions with existing brand, border, radius, and focus-safe tokens.
- Add regression coverage so the entries keep a visible action affordance and closed advanced content stays hidden by default.
