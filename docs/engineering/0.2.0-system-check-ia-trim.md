# 0.2.0 System Check IA Trim

Date: 2026-06-17

## Objective

Keep the System Check workspace focused on production readiness validation instead of duplicating Resource Management.

## 中文说明

系统自检页的主任务是验证核心权限链路、运行信号和上线相关状态。之前页面底部还直接挂了 Agent 注册表，容易让用户误以为系统自检也是资源生命周期管理入口。Agent 和 MCP 生命周期已经统一放在资源管理页，因此本次增量把系统自检页里的 Agent 注册表移除，减少页面职责混杂。

## Scope

- Frontend-only information architecture change.
- No backend API contract change.
- No self-check logic, preflight, runtime validation, resource lifecycle model, route, or data-loading behavior change.
- No new i18n keys.

## Changes

- Removed the `agentRegistryPanel` prop from `CockpitView`.
- Removed the Agent Registry panel from the `#cockpit` workspace.
- Kept Core Permission Loop Self-Check, runtime signals, runtime audit, and historical acceptance panels in System Check.
- Added a regression guard so `CockpitView` does not receive or render the Agent Registry again.
