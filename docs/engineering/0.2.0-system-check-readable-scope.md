# 0.2.0 System Check Readable Scope

Date: 2026-06-17

## Objective

Remove raw tenant and workspace identifiers from the primary System Self-Check context strip. Operators should see the same business-readable tenant and workspace labels used elsewhere, while raw IDs remain available for troubleshooting.

## 中文说明

本次增量处理系统自检页顶部“范围”区域：原来直接显示 `default` 和 `workspace-sandbox`，对非技术用户不友好。现在主界面展示“集团总部”“客户服务工作区”等业务名称，悬停标题里仍保留原始 ID，方便排查。

## Scope

- Frontend-only change.
- No backend API contract change.
- No management scope mutation change.
- No query/filter behavior change.
- Reuses the existing tenant and workspace display helpers.

## Changes

- Compute business-readable tenant and workspace labels before rendering the System Self-Check context strip.
- Use the readable labels as visible text.
- Preserve the original tenant/workspace IDs in `title` attributes.
- Add regression coverage so the context strip cannot silently return to raw ID display.
