# 0.2.0 Visible Copy Production Language Hardening

Date: 2026-06-17

## Objective

Keep AgentHarbor's operator-facing console language aligned with a production B2B management system. The console should not expose forensic-sounding "evidence / 证据" wording in visible labels, messages, or fallback text; internal API names and historical engineering docs remain compatible.

## Scope

- Frontend-only change.
- No backend API rename.
- No dependency change.
- User-visible English and Chinese copy must prefer acceptance reports, records, go-live checks, runtime records, audit records, and handoff materials.

- [x] Tighten the i18n regression test so every translated value is checked without key-based exceptions.
