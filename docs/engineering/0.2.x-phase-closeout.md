# AgentHarbor v0.2 Developer Preview Phase Closeout

Status: closeout candidate for `v0.2.0-dev-preview`.

AgentHarbor v0.2 is ready to close as a developer-preview phase when the repository records a clean local release gate, clean CI, a bounded release note, and a next-stage evaluator loop. This closeout does not claim production readiness.

AgentHarbor v0.2 可以作为开发者预览阶段封口的条件是：仓库记录本地发布门禁通过、CI 通过、有边界的发布说明，以及下一阶段外部评估流程。本文档不声明生产可用。

## Scope

Included in this phase:

- Tenant, workspace, caller, capability, and data-scope governance.
- Permission Changes with deterministic package drafts, simulation, approval routing, read-only preflight, transactional apply, health, impact, go-live status, and acceptance-report export.
- Scoped and managed administrator boundaries.
- Tenant Permission Center and Access Profile views.
- Management MCP metadata for safety, access, lifecycle, execution, and write confirmation.
- Local demo, scenario gates, release gates, and evaluator-readiness pack generation.

Excluded from this phase:

- Production traffic.
- Customer-specific MCP endpoint validation.
- Identity-provider integration.
- Access Handoff and My Access self-service.
- OpenAPI capability discovery beyond the current proxy boundary hardening.
- First-class database, warehouse, model, or skill-bundle permission resources.
- Automated rollback execution.
- Multi-region production deployment.

## External Evaluation Gate

Before starting v0.3 implementation, run the evaluator loop from `docs/product/evaluation-readiness.md`.

Success bar:

- Three fresh evaluators finish under 30 minutes.
- Each evaluator exports an acceptance report.
- Each evaluator can explain the allowed capability, denied capability, permission package, access recipient, and report digest.
- Repeated blockers are fixed before opening Access Handoff implementation.

## Next Stage

If the evaluator loop passes, start v0.3 with Access Handoff:

- copyable MCP config
- prompt guidance
- short-lived token handling
- handoff references tied to approval, application, runtime, audit, and report records

If the evaluator loop fails, do not start Access Handoff yet. Fix the repeated setup, Permission Changes, report-trust, or documentation blockers first.
