# AgentHarbor v0.4.1 Release Notes

Status: released 2026-09-30. Patch release on top of v0.4.0: the round-5
external-evaluation fixes, a local-gate server-leak repair, and dependency
updates. No schema changes, no new migrations, no API contract changes.

## Highlights

- Approval detail shows what a request allows (round 5, finding #38). The
  detail previously rendered only template guardrails, and the built-in
  templates deny by guardrail only, so the approver never saw the allow side
  of a change. The request snapshot's allowed keys now render as success rows
  next to the guardrails, and the pending-approval notification counts match
  (PR #406).
- The Access Handoff "copy config" artifact carries a full URL (finding #39).
  The backend emits the config origin-agnostic by design; the console now
  prefixes its configured API base onto the relative url before copying,
  matching the shell snippet on the same card. Placeholder headers are
  untouched (PR #406).
- Local gates no longer leak servers (PR #405). Scenario scripts and the
  Makefile wrapper build the API once and run the binary directly instead of
  `go run`, so an aborted run no longer orphans a compiled server holding its
  port; port-listener TERM/KILL fallbacks run after every scenario.
- Dependency updates (PRs #383–#385): chi 5.3.2, a pgx minor bump, vite
  8.3.1, React 19.3, @vitejs/plugin-react 6.1.1, lucide-react 1.48, and
  TypeScript 7.0.2. The production bundle built under TypeScript 7 is
  byte-identical to the TypeScript 6 build.

## Compatibility notes

- No migrations beyond 015 (unchanged since v0.4.0); upgrading is a binary
  swap, and rollback is the previous binary.
- No API contract changes. The v0.4.0 console compatibility contract (legacy
  bare-hash redirects, not-found page for unknown slash-shaped hashes) is
  unchanged.
- The backend's `mcpClientConfig` copy artifact is unchanged and still
  origin-agnostic; absolutizing happens in the console at copy time.
- TypeScript 7 replaces the compiler toolchain only; CI continues to run the
  frontend matrix on Node 24 and 26.

## Verification

- Frontend tests 260/260; `make check`, `make release-check`, and
  `make evaluation-readiness` green on the tagged tree.
- PR CI 6/6 on #405, #406, #383, #384, #385; main CI green after each merge.
- TypeScript 7 validated locally before merging: `tsc -b` clean over the whole
  frontend, production bundle hash identical to the TypeScript 6 build,
  260/260 tests.
